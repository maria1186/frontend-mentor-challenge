## Key Features

This project includes the following functionalities:

- **Responsive Design:** Optimal layout for the interface depending on the device's screen size.
- **Interactive Elements:** Full hover and focus states for all buttons and links.
- **Mobile Navigation:** Smooth open and close actions for the navigation menu on smaller screens.
- **Clipboard Integration:** One-click functionality to copy the Wi-Fi password to the clipboard.
- **Advanced CSS Animations:** Custom hover effects that animate the receipt and host-note cards to fan out smoothly.
- **Print Optimization:** The "Print receipt" button triggers a clean, styled print view using the browser's native print dialog.
- **Calendar Integration:** Dynamically generates a downloadable calendar file (.ics) from the stay dates so guests can easily save their booking.
- **Dynamic Data Loading:** All booking details are loaded asynchronously from a JSON file instead of being hardcoded into the HTML.
